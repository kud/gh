The inbox search bar now says which state it is in. A kept filter used to look exactly like a field still taking keys, so nothing on screen said whether the next letter would type or fire a hotkey. The bar now draws a nerd-font magnifier where text mode keeps the `/`, stays lit with a caret while typing, and once the query is kept it dims down and rewords its hints to `filtered · keys active · esc clear`. Match counts and every key behave exactly as before.
